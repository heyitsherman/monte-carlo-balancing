# Teaching kit

Everything needed to teach Monte Carlo simulation as an add-on to game design fundamentals with "Run it 10,000 times": from a 5-minute slot to a 90-minute segment. Students need no code.

| File | For | What it is |
| --- | --- | --- |
| [Facilitator guide](facilitator-guide.md) | The facilitator | Segment menu with timings and links, notes per chapter (what to ask, misconceptions, discussion prompts), what to do when things don't go to plan |
| [Dice activity](dice-activity.md) | The facilitator | 10 minutes, no screens: the class pools its dice rolls, then compares with 10,000 simulated battles |
| [Exercises](exercises.md) | Students | 17 Lab exercises in three tiers (Explore, Tune, Design), each a link that opens the Lab with its rules set |
| [Answer key](answer-key.md) | The facilitator | Answers with the Lab's numbers and the exact ones, plus reference tables and what strong answers look like for Design |
| [Worksheet](worksheet.md) | Students | Template for recording work at any tier: predict, run, explain; target and attempts; target, defence and A/B evidence |

**Tiers are by depth of design thinking, not by tool.** Everyone uses the same Lab:

- **Explore:** predict, run, explain why you were right or wrong.
- **Tune:** change the rules until the game hits a target someone else chose.
- **Design:** choose your own target, defend it, then find rules that hit it.

**The worksheet is meant to be edited.** The file here is the template; copy it into a doc (or print it) and change the questions for each class.

**Numbers.** Every number in the kit is from the default seed (`dgt-balance`), so the links show exactly what the answer key says. They match `npm run calibrate` and the README's "Measured numbers". If a game's rules or the simulation change, regenerate them and update the answer key.
