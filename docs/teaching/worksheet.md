## Words you'll need

- **Run:** one simulated game (or battle, fight, series, player).
- **Likely range (±):** where the true answer probably is. More runs make it narrower.
- **Target band:** the range of results the designer decided counts as "right", for example "fair" = 47–53%.
- **Verdict:** whether the whole likely range sits inside the target band. "Not enough data" means it crosses the edge: press **N** to run 10 times more.
